# ガチキャリア LP（Mac向け・はじめてでもわかる手順）

このフォルダには、Webページを表示するためのファイルが入っています。

- `index.html`（ページ本体）
- `styles.css`（見た目のデザイン）
- `script.js`（ボタンを押した時の動き）
- `assets/`（画像）

---

## まず結論（いちばん簡単）

Mac だけあれば、**ターミナル1つでテスト表示**できます。

1. ターミナルを開く
2. このフォルダに移動する
3. コマンドを1つ実行する
4. ブラウザでURLを開く

以下、1つずつ超ていねいに説明します。

---

## 最初にやること（渡された画像をそのまま使う）

受け取った画像を以下の名前で `assets` フォルダに置いてください。

- `assets/fv.jpg`（FV画像）
- `assets/strength.jpg`（強み画像）

> この2ファイルがあれば、ページは**渡された画像そのまま**で表示されます。

---

## 1. ターミナルを開く

- `command + space` を押す
- 「ターミナル」と入力して Enter

---

## 2. フォルダに移動する

このプロジェクトが `/workspace/html_create` にある前提です。

```bash
cd /workspace/html_create
```

> もし別の場所にある場合は、その場所に合わせて `cd` の後ろを変更してください。

---

## 3. テスト用のミニサーバーを起動する

以下を実行します。

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

成功すると、だいたい次のような表示になります。

```text
Serving HTTP on 0.0.0.0 port 4173 ...
```

この画面のままでOKです（閉じない）。

---

## 4. ブラウザで表示する

Safari / Chrome で次を開きます。

- <http://localhost:4173/index.html>

これでページが見られます。

---

## 5. サーバーを止める

ターミナル画面に戻って、`control + C` を押します。

---

## よくあるつまずき

### Q1. `python3: command not found` と出る

MacにPythonが入っていない状態です。まずはPython3をインストールしてください。
（インストール後、もう一度同じコマンドを実行）

### Q2. ページが真っ白 / 崩れて見える

- URLが `http://localhost:4173/index.html` になっているか確認
- `assets` フォルダが `index.html` と同じ階層にあるか確認

### Q3. ボタンが赤くならない

`script.js` が読み込めていない可能性があります。ファイル名のスペルと配置を確認してください。

---

## サーバーにアップロードする時（本番反映）

以下を**同じ階層のまま**アップロードします。

- `index.html`
- `styles.css`
- `script.js`
- `assets/`（フォルダごと）

アップロード後に、公開URLへアクセスして表示確認してください。

---

## Dockerで確認したい場合（任意・上級者向け）

Docker Desktop が入っている場合のみ使います。

起動:

```bash
docker compose up -d --build
```

表示:

- <http://localhost:8080/>

停止:

```bash
docker compose down
```
